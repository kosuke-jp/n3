# N3 試験直前 満点サプリ

韓国語話者向け JLPT N3 クラスの学習ページ（GitHub Pages で公開）。

- `index.html` — トップページ（テスト一覧）
- `100sen-1.html` — 紛らわしい濁音・長音 熟語100選 ①（1〜50）
- `100sen-2.html` — 紛らわしい濁音・長音 熟語100選 ②（51〜100）
- `bunkei-up.html` — 得点アップ 文型チャレンジ（6セット×36問、得点アップドリル文型01〜06から）
- `bunkei30.html` — 必須文型30チャレンジ（確認問題30＋文型カード30、Band配布PDF「N3 필수 문형 30」から）
- `yomi-fukushi.html` — 得点アップ 読み方＆副詞チャレンジ（2セット×32問、第4回模試前の総仕上げ）
- `kakunin3.html` — 第3回模試 ふりかえりチャレンジ

## 自動でやっていること（.github/workflows/cards.yml）

main に反映されるたびと、毎日0:05（韓国時間）に `tools/update_cards.py` が動きます。

- 各ページの追加日・更新日を git の記録から読み、`<meta name="n3-updated">` とトップページの一覧に書き込む
- `og/base/` の画像に「NEW m/d」「UPDATE m/d」の帯を付けて `og/` のカード画像を作る（7日で自動的に外れる）
- `og:image` のURLに `?v=日付` を付けて、カカオトークに新しいカードを読み直させる

コミットメッセージに `[no-update]` を入れると、そのコミットは「更新」として数えません（見た目だけの修正など）。
各ページの「🔗 共有」ボタンは、末尾に更新日（`?v=日付`）を付けたURLをコピーします。
